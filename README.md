# MathQuest

Казахскоязычная платформа по математической грамотности для 11 класса: 15 разделов, 153 темы, 586 заданий, 45 интерактивных миссий и 15 лабораторий. Учитель создаёт класс, ученики регистрируются по коду со своих устройств, а прогресс каждого ученика виден в журнале класса.

Автор учебного содержания — Рахметқұлова Жаңыл Рахметқұлқызы (№6 орта мектебі).

## Как устроено

- **GitHub → Vercel.** Каждый push в `main` публикуется автоматически. Сборка не нужна.
- **Сайт** — статические файлы в корне репозитория.
- **Сервер** — одна функция Vercel `api/rpc.js` (аккаунты, классы, прогресс, задания). Пароли хешируются (scrypt), вход по токену сессии.
- **База данных** — Redis, подключённый в Vercel → Storage. Подходит Upstash for Redis (переменные `…_REST_API_URL` + `…_REST_API_TOKEN`) или Redis (переменная `…REDIS_URL`) — с любым префиксом, сервер находит их сам.
- Если база не подключена или сайт открыт как файл, он работает в локальном режиме: данные только в этом браузере.

## Подключение базы (один раз)

1. Vercel → проект **mathquest** → вкладка **Storage** → **Create Database** → **Upstash for Redis** (план Free) → **Connect** к проекту.
2. **Deployments** → у последнего деплоя **⋯ → Redeploy**, чтобы функция получила переменные.
3. Открыть сайт: на странице входа не должно быть жёлтой надписи «Дерекқор қосылмаған». Проверка сервера: `POST /api/rpc` с телом `{"op":"ping"}` → `"storage": true`.

## Разработка

```bash
python3 -m http.server 8000   # локальный режим без сервера: http://localhost:8000
```
