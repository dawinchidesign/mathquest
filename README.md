# MathQuest

Казахскоязычная платформа по математической грамотности для 11 класса: 15 разделов, 153 темы, 586 заданий, 45 интерактивных миссий и 15 лабораторий. Учитель создаёт класс, ученики регистрируются по коду, а прогресс каждого ученика виден в журнале класса.

Автор учебного содержания — Рахметқұлова Жаңыл Рахметқұлқызы (№6 орта мектебі).

- Статический сайт без сборки и без сервера: публикуется на Vercel прямо из этого репозитория (`vercel.json`).
- Аккаунты, классы и прогресс хранятся в localStorage браузера — внешних баз данных нет.

## Разработка

```bash
python3 -m http.server 8000   # http://localhost:8000
```
