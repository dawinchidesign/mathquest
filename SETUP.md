# MathQuest — запуск и подключение облака

Сайт работает в двух режимах:

| Режим | Когда | Где хранятся аккаунты и прогресс |
|---|---|---|
| **Демо** | `js/config.js` не заполнен | Только в браузере этого устройства. Удобно, чтобы посмотреть и проверить. |
| **Облако (Supabase)** | В `js/config.js` вписаны URL и ключ | В общей базе. Ученики заходят с любых устройств, учитель видит весь класс. |

Чтобы учитель видел прогресс учеников, нужен режим «Облако». Настройка занимает около 10 минут и бесплатна: бесплатного тарифа Supabase хватает на несколько классов.

---

## 1. Создать проект Supabase

1. Зайдите на <https://supabase.com> → **Start your project** и войдите через GitHub.
2. **New project**: имя `mathquest`, придумайте пароль базы данных (сохраните его), регион — ближайший (например, Frankfurt).
3. Подождите 1–2 минуты, пока проект создаётся.

## 2. Создать таблицы

1. В проекте откройте **SQL Editor** → **New query**.
2. Откройте файл `supabase/schema.sql` из архива, скопируйте **всё содержимое** и вставьте в редактор.
3. Нажмите **Run**. Должно появиться `Success. No rows returned`.

Скрипт можно запускать повторно: существующие данные не удаляются.

## 3. Отключить подтверждение email (обязательно)

Ученики регистрируются по **логину**, без почты. Поэтому подтверждение email нужно выключить:

**Authentication → Sign In / Providers → Email** → выключите **Confirm email** → **Save**.

> Если оставить его включённым, учителя будут получать письмо для подтверждения, а регистрация учеников по логину не будет работать.

## 4. Вписать ключи в сайт

1. **Project Settings → API** (или **Data API**). Скопируйте:
   - **Project URL**, например `https://abcdxyz.supabase.co`;
   - ключ **anon public** (длинная строка, начинается с `eyJ...`) или **publishable key** (`sb_publishable_...`).
2. Откройте `js/config.js` и вставьте их:

```js
window.MATHQUEST_CONFIG = {
  SUPABASE_URL: 'https://abcdxyz.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...',
  STUDENT_EMAIL_DOMAIN: 'student.mathquest.app',
  SCHOOL_NAME: '№6 орта мектебі'
};
```

> Ключ **anon / publishable** публичный: его можно класть на сайт, данные защищают правила RLS в базе. Ключ **service_role / secret** никогда не вставляйте в сайт.

## 5. Опубликовать

**Netlify (проще всего):** <https://app.netlify.com/drop> → перетащите папку с `index.html`.
Чтобы сайт обновлялся автоматически, подключите GitHub-репозиторий: Netlify → **Add new site → Import from Git** → выберите репозиторий. Сборка не нужна (Build command — пусто, Publish directory — `.`).

**Cloudflare Pages:** Direct Upload → загрузите папку.

## 6. Первый урок

1. **Учитель:** откройте сайт → **Тіркелу → Мұғаліммін** → создайте класс. Появится 6-значный код.
2. Нажмите **«Тақтада көрсету»**: код и адрес сайта откроются крупно для доски.
3. **Ученики:** сайт → **Тіркелу → Оқушымын** → код класса, имя, логин, пароль.
4. Учитель видит в **«Сынып журналы»**:
   - тепловую карту освоения по 15 разделам;
   - точность ответов, XP, последнюю активность;
   - кому нужна помощь (не заходил больше 7 дней или точность ниже 50%);
   - карточку каждого ученика: слабые разделы, активность за 14 дней, история тренировок;
   - **Тапсырмалар**: задания по темам с отслеживанием выполнения;
   - экспорт журнала в CSV для Excel.

**Ученик забыл пароль?** Журнал → ученик → **«Жаңа құпиясөз»**. Учитель задаёт новый пароль и сообщает его ученику.

## Как это устроено

- `index.html` — оболочка страницы.
- `css/app.css` — дизайн-система «Дәптер»: тетрадь в клетку, чернила, красное поле.
- `js/config.js` — настройки Supabase.
- `js/cloud.js` — работа с облаком: Supabase или локальный демо-режим, API у обоих одинаковый.
- `js/app.js` — ядро: прогресс, синхронизация, страницы ученика, тренажёр.
- `js/labs.js` — 15 интерактивных лабораторий и диаграммы.
- `js/auth.js` — вход и регистрация.
- `js/teacher.js` — журнал класса, карточка ученика, задания, рабочие листы.
- `data/*.js` — учебный контент: 15 разделов, 153 темы, 586 заданий (не менялся).
- `supabase/schema.sql` — таблицы, правила доступа (RLS) и функции.
- `js/vendor-supabase.js` — официальная библиотека [supabase-js](https://github.com/supabase/supabase-js) v2.118, MIT. Лежит внутри проекта, поэтому сайт работает без внешних CDN.

**Синхронизация.** Прогресс сначала сохраняется в браузере, затем через 1–2 секунды отправляется в облако. Без интернета сайт продолжает работать (это PWA), а прогресс отправится, когда связь появится. Если ученик занимается на двух устройствах, прогресс объединяется без потерь.

**Безопасность (RLS).**
- Ученик видит и меняет только свой прогресс.
- Учитель видит только учеников своих классов.
- В класс можно войти только по коду.
- Роль «учитель/ученик» нельзя изменить после регистрации.

Все правила проверены автоматическими тестами на настоящем PostgreSQL.

**Ограничение.** Регистрация учителя открыта: любой может создать учительский аккаунт. Он увидит только своих учеников, к чужим данным доступа не получит.
